Project 1 — Network Scanner with Nmap

What this project does
Scans a local network to discover live hosts, open ports, and running services
using Nmap — the same tool used by professional penetration testers.

# Tools used
- Nmap
- Bash (Linux terminal)

# How to run it
1. Install Nmap: `sudo apt install nmap`
2. Run the script: `./scan.sh`
3. Results are saved in the `scan_results/` folder

# What I learned
- How to discover devices on a network
- What open ports reveal about a system
- How to document findings like a security report
